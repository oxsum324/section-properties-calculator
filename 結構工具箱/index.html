高頻局部計算建議

基礎局部檢核、設備局部荷重、擋土土壓與地坪 Westergaard 已具多案例基準、版本化 JSON 與計算書結果鏈；地坪工具明確限於 Winkler 彈性地基上的載重彎拉應力，疲勞、接縫傳力與沉陷另行檢核。懸臂式主動土壓結果亦可經同版核心驗證後銜接 RC 基礎牆身、趾版底層與踵版頂層設計。覆工板控制柱頂軸力現在可經現行核心重算及雙指紋核對後，以固定柱位 ID 逐階段套用到指定開挖共構柱；同一來源跨柱分配時會封閉檢查啟用柱位比例合計為 100% 並要求逐柱依據，再以各柱採用軸力進行多階段包絡，亦可逐階段明確採用附加 X／Y 偏心與依據。開挖支撐與斜撐匯入已保留完整軸力時序，拆撐承接回簽亦已逐列結構化記錄正式模型、控制組合、傳力、偏心、極限狀態與證據檔。下一波應依成熟度矩陣與巡檢儀表板，開發特定承接型式容量計算模組及 SRC 構件能力；新工具仍須先定義適用範圍、規範依據、golden cases 與計算書邊界。

使用邊界

各工具僅得於頁面標示之適用範圍內使用；超出適用範圍者不得直接採用計算結果。最終結構設計與圖說仍應由執業技師簽證。
