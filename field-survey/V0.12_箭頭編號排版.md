# V0.12.0 箭頭與照片編號排版

## 操作

1. 在「附件整理」完成選戶、選片及起始編號設定，再按「調整圖面編號」。
2. 選擇本戶／樓層的圖面。點圖上的編號，或從「照片編號」選單選擇；對應的箭頭變成藍色，其他箭頭暫時淡化，方便核對。
3. 點空白處移位，或按住編號拖曳。移位後自動鎖定；「微調」可按方向鍵小幅移動。
4. 「已鎖定」可解鎖；「避讓」重新排列未鎖定編號，保留已鎖定位置。「還原自動」只取消目前編號的位置設定。
5. 用雙指縮放／平移，或切換「移動」單指撥動畫面。「全圖」回到整張圖面。橫向時設定在左側，圖面在右側。
6. 按「保存編號位置」，再預覽標準附件或快速預覽。換圖或關閉前，未保存的調整會先提醒；復原／重做只保留本次編輯歷程。

## 編號與位置的關係

- 調整的是編號框及其細虛線，不是拍攝機位、方向或狀況位置。輸出時所有箭頭仍使用原始紀錄座標，編輯用的藍色與淡化不會印入報告。
- 相同拍攝點及方向的選片沿用共用箭頭；不同方向保持各自箭頭，不因距離近而合併。沒有新增 R 字首。
- 保存位置依「紀錄識別碼＋照片識別碼」或狀況位置識別碼引用，重新流水編號仍能找到原位置。重新編號後若字框變寬而重疊，鎖定框會要求人工移位；未鎖定框可自動避讓。
- 修改原定位或合併後的群組位置不一致時，附件會要求開啟編號編輯器核對保存。已下載附件保持原版本，後續更動請另行匯出。
- 位置保存在案件、單戶備份、完整備份及附件 JSON 圖面資料內；獨立還原會重配照片識別碼並保留對應位置。

## 避讓範圍與核對

本版避開編號矩形、圓圈、完整箭身及箭尖，並保留畫面邊界間距；共用向量排版用於圖面預覽與匯出。拖曳中只更新目前編號與引線，不反覆產生 JPEG；放開才重新計算周圍編號。

紅框代表仍有編號重疊或超出圖面，完成調整後才能保存及匯出。請勿為了排版移動真實拍攝點。箭頭本身可能因實際拍攝方向而交叉；可藉選取突出顯示逐一核對。

本版尚未自動識別底圖中的牆線、門窗、樓梯或房名，仍需在全圖與報告預覽中核對。向量底圖障礙物避讓、匯入影像的禁放區與密集區局部放大頁，列為後續階段。縮放方便操作，不會增加報告紙張上的可用面積。

## 驗證

- 66 項模型／備份回歸，涵蓋斜向箭身、箭尖、圓圈、鎖定優先、無法容納時拒絕、共享原圖的不同紀錄及重新編號。
- 瀏覽器實際點選／拖曳、方向微調、鎖定、解鎖、復原／重做、縮放、雙指及單指移動，並核對紀錄座標與人工說明未變更。
- 320／390／844 px 螢幕版面與渲染截圖；兩種報告的整體圖像指紋與共同排版輸出一致。
- 完整現場操作、原圖與圈註、兩種附件、分冊、離線及備份；250 戶／3,000 張合成照片的大量流程。
- V0.7／V0.9／V0.10.1／V0.11 原始 Git 程式建立舊案後升級，核對快取更新、原圖、欄位及舊視窗覆寫防護。
- 實體 iOS／Android 相機與觸控仍需現場試用；瀏覽器測試不等同實機驗證。

本版僅更新現況鑑定模組，發布採既有網站的模組覆蓋流程，其他工具維持原發布內容。
