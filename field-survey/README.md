# 現況鑑定紀錄 V0.1.0

先改善現場紀錄的試用版本。依「案件 → 鑑定戶 → 樓層／空間／位置 → 多張照片」工作，保存原圖、可編輯圈註、位置圖、量測值及語音備忘。

## 開啟與安裝

- 手機：從已發布的工具箱選「現況鑑定紀錄」，在線開啟一次，等上方顯示「離線已就緒」。可加入主畫面，再關閉網路試記一筆。
- 電腦：執行根目錄的 `啟動現況鑑定紀錄.bat`，固定使用 `http://127.0.0.1:4186/field-survey/index.html`。需要已安裝 Node.js；重開時沿用同一瀏覽器及網址。
- 手機使用需 HTTPS；電腦 localhost 可用。不要直接雙擊 HTML，也不要把電腦的 localhost 網址當成手機網址。
- 不同網址、瀏覽器或使用者設定檔有各自的本機資料。移轉時使用備份還原。

## 一次會勘的操作

1. 建立案件、會勘日期與鑑定戶。每次新的會勘可另建案件；本版尚無跨次會勘比對。
2. 在每個觀察位置新增紀錄，填樓層、空間與位置參照物。新增下一筆會沿用樓層和空間，現況與尺寸重新填寫。
3. 拍一張位置全景，再加入近照、量尺照。可直接拍照或從相簿多選，照片取得後即寫入案件。
4. 點照片可圈選、畫箭頭、畫線、加文字、設定用途與說明，按「保存圈註」。原圖與圈註分開存；「註記副本」產生 JPEG，長邊最多 4096 px，原圖保持原有位元組。
5. 使用「位置圖」加入同戶同樓層的圖面或草圖照片，從拍攝點拉向拍攝方向。本版接受可預覽圖片，不直接解析 PDF／CAD。
6. 選部位與可見現況。裂縫寬度使用 mm、長度使用 m；未量測保留空值，只有勾選實測才記尺寸。住戶陳述與觀察事實分欄，錄音每段最多 5 分鐘。
7. 離開一戶前看「待補檢查」，補位置、照片或尺寸；無法入內、部分完成要填原因。「本次紀錄完成」是紀錄進度，不是安全判定。
8. 進入「備份還原」匯出全案或單戶 `.csurvey`。下載動作完成後，確認檔案確實存入手機檔案或外部儲存位置。
9. 在電腦或另一裝置選擇備份，逐檔核對後建立還原副本，實際檢查照片與圈註。接收端可下載收據，帶回原裝置匯入。案件修改後會提示重新備份。

## 保存的範圍

資料只存在此瀏覽器的 IndexedDB 與自行匯出的備份，不自動上傳。離線快取只存工具程式，不存私人案件。照片不透過通訊軟體壓縮；工具保存的是瀏覽器提供的原始檔案，手機相機或相簿本身可能決定傳入格式。

發布流程排除 `.csurvey`、`-核對收據.json`，並檢查改名檔的備份標頭及 JSON kind；私人備份仍應存放在公司案件資料夾，勿放入程式庫。

照片不採用時填原因，原檔仍在備份裡。HEIC／HEIF 可保存；若裝置無法解碼，會提示不能預覽或圈註，仍可匯出原檔。錄音功能依瀏覽器麥克風權限與格式支援而定，沒有自動逐字稿。

同一案件在兩個視窗修改時會檢查版本，拒絕覆蓋較新的案件；「另存目前副本」可保留本視窗的紀錄，再人工核對。還原也建立新案件和獨立原檔識別碼，不覆蓋原案。

單一原檔上限 60 MB，備份媒體合計上限 2 GB；這是格式限制，並非手機容量保證。大量照片請按戶分包。持續保存權限與加入主畫面不能取代外部備份；清除網站資料、無痕模式或系統清理均可能影響資料。

備份核對使用 SHA-256，確認清單與原始媒體完整；核對收據不驗證拍攝地點、拍攝者身分或工程結論，也不是數位簽章。備份未加密，檔案分享對象與存放位置由公司管理。

## 本版交付與驗證

- 17 項資料／備份測試：空值和零值、單戶分包、完整還原、損壞與截斷、未列入資料、原檔遺失、收據過期、危險媒體格式、關聯及座標驗證。
- 真實桌機 Chrome 自動操作，模擬 390 × 844 手機尺寸：相簿加入、圈註對位、原圖雜湊、位置圖、量測、模擬麥克風錄音、離線重開與續寫、獨立瀏覽器還原與收據、損壞檔拒收、視窗衝突副本及無外部資料請求。
- 證據在忽略發布的 `output/field-survey-validation/`，全部使用合成測試資料。
- 尚未用實體 iPhone／Android 驗證相機、HEIC 解碼、主畫面安裝、鎖屏錄音及長時間大量照片。第一次使用先做一戶少量試拍、關網重開、再搬到電腦核對。

重跑資料測試：`node --test field-survey/tests/model.test.js`。瀏覽器測試：先備妥 `.github/pages-smoke` 的 Playwright runtime，執行 `node field-survey/tests/browser.test.js`；會自行開啟及關閉測試伺服器。Windows 使用已安裝 Chrome，其餘平台使用 Playwright Chromium。

## 後續更新順序

1. 以公司一戶實際試用結果調整按鈕、慣用文字、每戶拍攝順序及手機容量。
2. 建立桌機照片清冊、版面與 Word 工作稿，套用公司既有報告範本，由人工審閱後輸出。
3. 加入同一建物跨次會勘的範圍、原位置比對與逐次追加記錄。
4. 實際多人作業需求明確後，再規劃公司儲存空間、權限、同步衝突及稽核歷程。

本工具不判定損害原因、結構安全或責任歸屬，不產出正式鑑定結論。
