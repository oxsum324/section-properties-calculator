# V0.16.0 快速圖示擴充

依現場紀錄需求，將六款新增圖案加入「細部示意圖 → 圖示」。原有網裂、滲水痕、白華及剝落維持 V0.15.1 重繪樣式，共十種可快速放置的圖示。

| 新增圖示 | 示意畫法 |
|---|---|
| 鋼筋外露 | 不規則破損邊緣與網點，內部畫出帶肋鋼筋。 |
| 磁磚拱起 | 側視拱起輪廓、磁磚分界及抬升箭頭。 |
| 磁磚脫落 | 磁磚格網、缺磚處的網點底層與分離磚片。 |
| 正在漏水 | 裂口下方垂流線及水滴，與既有滲水痕區分。 |
| 磁磚破損 | 磁磚格網內的折裂、分岔與缺角。 |
| 油漆起泡 | 大小不同的圓滑隆起、弧線及少量起皮邊緣。 |

## 使用方式

1. 開啟本筆細部示意圖，選擇底圖。
2. 點「圖示」，選擇狀況後點圖面放置，可重複放置。
3. 點「選取」，可移動、縮放、旋轉、複製或刪除圖示；支援復原及重做。
4. 需要補充時，使用「裂隙」或「其他畫法／說明 → 自由手繪」。預設圖示作為整體操作，內部線條不能逐段拉動。
5. 保存後，PNG、快速預覽及標準附件會採用相同的向量圖案。

圖例只列本圖實際使用的種類，每列三種並自動換列；十種同時使用時為四列。編輯畫面超過四種時，以種類數顯示圖例摘要，保留畫布空間。

圖示僅表示觀察示意，不自動變更現場分類、量測、磁磚塊數或人工說明。磁磚拱起表示外觀隆起；空鼓需另外記錄敲擊等檢查結果。正在漏水供當時可見滴水或流水的情況使用，既有污痕仍可選「滲水痕」。

## 舊資料與備份

資料庫及備份版本升為 10。舊案件、照片、門窗框、既有細圖與量測資料保留；可讀取版本 1 至 9 備份。舊版視窗會被阻止覆寫新版資料，避免不認得新增圖示的程式寫回。新備份須使用 V0.16.0 或更新版本還原。

## 驗證方式

- 模型與備份回歸包含全部十種圖示、既有觀察資料及還原。
- 瀏覽器專項驗證十款選取、放置、編輯、320／390／844 px 版面、離線保存、備份還原，以及四列圖例不超出圖片。
- PNG 與快速／標準附件使用同一份圖像，核對圖像指紋一致。
- 真實舊程式升級涵蓋 V0.7、V0.9、V0.10.1、V0.11、V0.12、V0.14 及 V0.15.1，檢查照片及紀錄保留、舊視窗禁止覆寫及離線操作。
- 發布仍採現況鑑定模組獨立流程，核對正式站檔案與來源版本。瀏覽器模擬不等同實體 iOS／Android 現場試用。
