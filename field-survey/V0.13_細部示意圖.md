# V0.13.0 細部示意圖

## 入口及操作

由「附件整理」每筆位置的「細圖」開啟。選底圖後進入繪製；底圖選單會收合，原有六種預設及自訂圖片保留。

| 工具 | 用法 |
|---|---|
| 裂隙 | 依序點起點與轉折點，按「完成筆畫」。兩點為直線，多點為折線。 |
| 範圍 | 選滲水痕、白華或剝落，至少點三個角點再完成。其他畫法內亦提供兩點範圍框。 |
| 符號 | 選網裂、滲水痕、白華或剝落的縮圖，再點圖面放置；可與手畫線條共存。 |
| 文字 | 輸入文字，再點圖面放置。 |
| 選取 | 點標記附近或用選單指定；拖曳整筆，或拖藍色控制點調整端點。重疊標記可再點切換，選單可精確指定。 |
| 移動 | 單指平移畫面；雙指在各繪製模式均可縮放、平移，另有放大、縮小、全圖按鈕。 |

「其他畫法／說明」提供自由手繪、兩點箭頭、兩點圈選、兩點範圍框與快速刪除。自由手繪須按住拖曳；單點不會留下看不見的零長度筆畫。

## 修正圖形

- 選裂隙線段後可刪除這段，其他段保留，不會自動跨越缺口連線。也可整筆刪除。
- 選中端點後可拖動或使用「位置微調」方向鍵；有足夠其餘端點時可刪除該點。大量手繪點只顯示部分控制點，避免畫面充滿把手。
- 選中符號後可縮小、放大、每次旋轉 15°、移動或複製。符號及一般圖形都可整筆刪除。
- 復原／重做保留本次編輯歷程。尚未完成的點線可用復原退回上一點，或取消整筆草稿。未完成時保存及匯出停用，避免漏存半條裂隙。
- 「左右鏡射」沿用整張底圖連同標記一起鏡射；重新建立底圖編輯器後不保留前一編輯器的復原歷程。更換底圖仍需確認清除當前標記，原已存紀錄在本次取消時保留。
- 編輯器對細線增加螢幕距離的選取容差，對控制點增加透明觸控範圍；縮放不改變原始標記座標。

## 符號語意與附件

四種符號是工具提供的一致示意樣式，非公會或 CNS 統一圖例。滲水痕採波紋，不以滴水圖示表示正在漏水。網裂用不規則交織線，非磁磚格網。符號的大小、線數及外框不代替實際裂隙數量、寬度、長度或面積。

放置符號不自動修改原紀錄的現況類型、量測、磁磚塊數或人工說明；網裂原有「不強制填寬度與長度」的規則保持不變。需要描述實際可見範圍時，另外圈定範圍。

PNG 包含乾淨底圖、損害標記與本張使用的符號圖例。標準照片說明表保留細圖並列符號名稱；快速預覽新增細圖頁，對照該筆照片編號。兩種附件使用相同 PNG 圖像，不將編輯中的藍色控制點或選取淡化印入報告。

細圖在照片說明表中會縮小；複雜圖形可使用快速預覽細圖頁或 PNG 放大核對。圖例及標記應人工核閱後併入鑑定附件。照片說明表不自動加入拍攝日期。

## 相容與驗證

僅現況鑑定模組進版，磁磚未新增功能，一般照片圈註及平面圖編輯維持既有操作。舊細圖的自由線、箭頭、圈選、文字與自訂底圖可保存、備份並還原。資料庫及備份版本為 8，沿用原資料庫名稱，讀取 1 至 7 舊備份；舊版寫入需先更新。

本版驗證包括 69 項模型／備份回歸、點選折線與範圍、端點拖曳、線段刪除、四種符號及複製變形、雙指縮放、取消手勢、320／390／844 px 畫布、舊細圖保留、離線重開與獨立備份還原。兩種附件中的細圖與 PNG 的圖像指紋一致；原紀錄、量測、磁磚欄位及人工文字不因新增符號而改動。

完整瀏覽器流程與五個真實 Git 舊版升級驗證通過，並保留既有 250 戶／3,000 張合成照片分冊測試。實體 iOS／Android 手機仍需現場試用，瀏覽器測試不代替實機驗證。
