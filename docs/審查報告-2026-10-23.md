## 其他已修正項目

下列錯誤偏保守、只影響計算書顯示，或誤差小於 3%，一併修正。

- **斷面性質**：H 型鋼圓角形心 0.7766R → 0.2234R（H400×200 Ix 23,635 → 23,704 cm⁴，JIS 23,700）；rT 改 hw/6；唇形 C 型鋼位置與 Sy；梯形、拋物線 e/e₁ 對調；合成斷面母材同一圓角錯誤。
- **RC 補強斷面**：外貼鋼板／FRP 轉換面積 (n−1)A → n·A（I −2.6%）。
- **錨栓剪破**：√da 誤寫 da^0.2（過度保守約一半），le 加 ≤ 8da 上限。
- **覆工板**：半結實翼板 Fb 公式單位錯誤，算出 −7,910 kgf/cm²。
- **開挖擋土支撐**：F1-6 區段未與 F1-8 取大（過度保守最多 34%）。
- **風力**：Kz 在 z ≤ 5 m 的下限誤用 zmin（地況 A 偏保守 46%，地況 C 偏低）；用途係數 1.15/0.95 → 1.1/0.9；式 2.15；部分封閉 GCpi 1.146；小面積 GCp 折點；招牌／招牌桿表 2.10、2.13 參數。
- **地震力**：式 (C2-11b) 常數 0.096；柱垂直係數補 αy；盆地 Ra 公式顯示 /1.5 → /2。
- **RC 構材**：壓力伸展長度 ℓdc 誤用 SI 係數（#8：458.7 → 47.8 cm）；梁 Av<Av,min 時 λs 乘錯項；牆最小鋼筋比依號數與 fy 區分。
- **RC 基礎**：單向剪力斷面寬；聯合基腳邊柱 b0、αs；筏基單向剪力寬度；Vesic Cs √(L/D)。

**預設案例判定改變**：樁帽預設例撓曲改判 NG（實配 62.1 cm² < 最小量 86.4 cm²），舊版通過是 AsProv 恆取需求量所致。

## 範圍、方法與限制

- **方法**：以 Node／Python 抽出計算函式，對照結構力學閉合解、規範公式手算或獨立撰寫的參考實作；不採用工具自身的黃金案例為預期值。只有能以數值重現者列為錯誤。
- **規範依據**：耐風 103 年版、耐震 111 年版＋2022-07-08 勘誤、混凝土 112 年版（部分以 ACI 318-19 換算對照）、鋼構 AISC 360 體系、SRC 100 年版、錨栓 ACI 318 第 17 章。
- **獨立基準也有錯**：風力、地震、鋼構連接板、RC 樁的 oracle 抄了工具的同一錯誤，導致修正前全數「通過」；已改為獨立寫法。
- **未執行**：全平台治理契約測試、黃金案例收割、各工具 PDF／列印／TXT 下載檢核（容器環境限制；原檔亦同樣失敗）。
- **未審查**：石材固定 HTML 主體、錨栓底板／側面爆裂／握裹段、開挖前端與報表、單剪力板與梁柱接頭、RC 補強剪力與 FRP、擋土牆分頁。開挖後端本身沒有土壓、貫入、隆起計算（由外部分析檔匯入）。
- **職責邊界**：本報告是程式審查紀錄，不取代技師對工具驗證域與指定案件適用的工程判斷。
