# SRC 構材工具

本目錄提供包覆型 SRC 梁正式工具：純函式核心、規範追溯、案件 JSON、精簡計算書、內部審閱／正式附件核可，以及真實瀏覽器列印驗證。公開入口為 `/src-beam`，首頁材料系統可直接切換至 SRC。

## 正式規範基準

- 內政部《鋼骨鋼筋混凝土構造設計規範與解說》100 年修正版，100 年 7 月 1 日施行。
- 法規入口：<https://www.nlma.gov.tw/ch/legislation/regsearch/977>
- 第 3 章：鋼骨寬厚比與一般要求。
- 第 5 章：包覆型 SRC 梁強度疊加、鋼骨／RC 剪力分擔、一般剪力與剪力摩擦控制。

2024 年內政部建築研究所已完成 SRC 設計與施工規範修正草案，但研究報告明列尚待後續規範審查。本核心不將草案當作現行法規。

## v0.1 適用範圍

- 完全包覆型矩形 SRC 梁，鋼骨為置中雙對稱 H 型斷面。
- 無軸力之撓曲與剪力檢核，非耐震設計。
- RC 撓曲部分支援單筋或雙筋矩形斷面，以平面應變與矩形壓力塊求中性軸，允許壓力筋未降伏。
- 鋼骨彎矩依 `Mns = ZFys`，整體設計彎矩依式 (5.4-1)。
- 剪力依式 (5.5-1) 與 (5.5-2) 分別檢核鋼骨及 RC 部分，不以單一相加容量掩蓋任一部分不符。
- RC 剪力同時計算一般剪力與剪力摩擦，取較小者。

## 失敗封閉邊界

下列條件不得用 v0.1 計算結果作通過判定：未知輸入 schema、耐震設計、軸力、非完全包覆、梁端主筋不連續或未錨定、主筋與鋼板淨距小於 25 mm、未明確確認常重混凝土與整體澆置剪力摩擦面、剪力釘貢獻、未納入的梁柱接頭與施工階段強度。

若未提供臨時支撐，混凝土凝固前的鋼梁靜載重強度與穩定必須另案複核；本項屬正式狀態的人工複核條件，不能因構材強度數值通過而消失。

## 獨立工程基準

`結構工具箱/tools/independent-engineering-benchmarks.catalog.json` 已將 `/src-beam` 納入正式入口獨立基準，包含 4 組案例與 41 項斷言。production 核心以應變相容與二分法求中性軸；獨立 oracle 在張力筋降伏、壓力筋彈性的明確適用域內改用二次方程封閉解，並獨立重算撓曲、400／490 MPa 寬厚比、鋼骨／RC 剪力分擔、一般剪力、剪力摩擦及需求比。

此基準失敗會阻擋平台的獨立工程基準 gate；SRC 梁現已計入 32 / 32 個正式工具入口。

## 正式操作頁與附件邊界

- `src-beam.html` 提供完整輸入、結果總覽與規範適用條件；工程名稱、編號及設計者均可留空，由主文承接，不影響附件核可。
- HTML 與計算書共用同一張「SRC 梁計算斷面圖」：混凝土及置中 H 型鋼依 `b、h、D、bf、tw、tf` 採用尺寸同比例繪製，並標示 `d、d′、dv、As、As′、Av/s`。現階段鋼筋只有計算面積與有效深度，圖面明確界定為計算斷面而非施工配筋詳圖；不臆造鋼筋根數、號數或層位。
- 案件 JSON 使用 `src-beam.case.v1`，匯入時檢查 schema、工具、版本與重算指紋；不一致時保留原輸入並失敗封閉。
- 計算書只列採用規範、構材條件、需求、斷面、材料、公式、代入值、檢核結果及結論。操作提醒、適用邊界卡與待複核閱讀狀態只留在 HTML 工作頁。
- 計算書預設為可列印的內部審閱；明確勾選核可後才成為正式附件。核可人與核可依據為選填，但核可後若變更，會自動撤銷並要求重新核可。
- 直接列印操作頁只顯示一頁封鎖通知；必須由「產生計算書」開啟附件輸出。
- `src-beam.contract.test.js` 固化報告純度、計算斷面、空白案件欄位、案件重播與指紋契約；`src-beam-browser-smoke.test.js` 以真實 Chromium 驗證圖面同步、無效幾何清除舊圖、JSON 往返、核可撤銷、列印媒體與正式 PDF。

正式 release 會把 SRC 梁 PDF、來源案件 JSON、計算指紋與雜湊證據寫入當輪私有證據目錄；公開頁只呈現完成數，不公開案件內容或雜湊。

## SRC 柱研究核心（尚未公開）

`core/src-column-core.js`、`core/src-column-h-section-catalog.js`、`core/src-column-rc-biaxial.js`、`core/src-column-shear.js`、`core/src-column-seismic-axial.js`、`core/src-column-seismic-detailing.js`、各自回歸測試，以及獨立的 `core/src-column-oracle.js`／`src-column-oracle.test.js` 已建立 SRC 柱第八階段可審查核心，並以內政部建築研究所《鋼骨鋼筋混凝土(SRC)構造設計教材》例題 8 與例題 14 的可適用算術範圍回歸。目前實作包含：

- 第 3.4 節表 3.4-2 翼板 `b/tf` 與腹板 `hc/tw` 自動重算；一般模式以 `λp` 判定，啟用耐震剪力子檢核時改以 `λpd` 判定。
- 式 (7.3-3)~(7.3-6) 鋼骨與 RC 部分軸力／彎矩剛度分配。
- 式 (6.4-2)~(6.4-5) 包覆型 H 鋼骨有效迴轉半徑、細長比參數與軸壓強度。
- 式 (7.3-7)~(7.3-8) 鋼骨雙軸壓彎互制；式 (7.3-9)~(7.3-10) 的 β 同時包含軸力、Mux 與 Muy 三項，再明示重新分配鋼骨／RC 需求。
- RC 單軸部分使用現行共用應變相容 P-M 核心；雙軸部分要求每支主筋具 x／y 座標，以精確矩形半平面裁切、連續中性軸二分法及 72 方向掃描建立定軸力 Mux-Muy 互制曲面。強度折減轉換依 112 年規範採 `εty=fy/Es` 至 `εty+0.003`。
- 第 9.3 節耐震軸向強度子檢核以式 (6.4-1)、(6.4-6)~(6.4-7) 重算完全包覆橫箍筋柱設計受壓強度，再檢核式 (9.3-1)、(9.3-2) 正負地震方向。`Fu` 由專案確認並明示 2.5 上限；停車場、公眾集會場所或活載超過 0.5 tf/m² 時改採 1.0 活載係數。1.25 倍接頭／相接構材傳力上限與彎矩構架免檢都必須主動選用且補齊確認；產生拉力需求時，拉力設計強度必須由專案核定，工具不計入混凝土拉力或自行推定。
- 第 9.6.2 節強軸耐震柱剪力子檢核由 `Vu=(Mct+Mcb)/hn` 建立需求，以 `Mpr=Mns+Mprc` 分配鋼骨與 RC 需求；`Mprc` 以 `1.25Fyr` 純彎應變相容重算。鋼骨依式 (5.5-3)，RC 依式 (5.5-4)~(5.5-13) 同時計算一般剪力與剪力摩擦並取小者，兩部分必須分別通過。
- 第 9.6.1 節單一強軸梁柱接頭強柱弱梁子檢核要求順、逆時針分別滿足 `ΣMc/ΣMb ≥ 1.2`，並要求確認柱容量取自各載重組合軸力下之最小接頭面標稱彎矩；其他接頭與正交方向不由工具推定。
- 第 9.6.3 節強軸矩形柱圍束子檢核採現行式 (9.6-6)~(9.6-10)，由剪力子檢核自動帶入箍筋量下限，另核對圍束範圍、圍束／非圍束間距、第一箍筋、主筋續接與繫筋確認。現行公式包含 `Phcc`，非圍束區間距上限為 15 cm；教材例題 14 的省略項與 20 cm 舊值不作現行判定。
- 第一批斷面 catalog 逐列核對教材附錄（一）表 1-1「RH 型鋼斷面性質（續 4）」印刷頁 289／PDF 第 301 頁，涵蓋完整 H500×300 群組 7 筆；catalog 提供尺寸與 A、Ix、Iy、Zx、Zy，使用者另填的不一致數值會失敗封閉。
- 未選 catalog 仍可進行研究計算，但固定列出 `section-properties-manual` 複核；catalog 的教材星號只保留出版時的依訂單生產註記，不證明現況供貨，也不取代專案規格與材證。
- 教材例題 8 的 12-#8 依斷面圖「四角各 3 支」保存 `y=7/17/63/73 cm` 四層及 12 支實際 x／y 座標；連續應變相容結果約 121.4 tf-m，教材圖表內插 126.5 tf-m 只作 5% 近似交叉檢查。
- 獨立 oracle 不引用正式核心、catalog、共用 P-M、正式雙軸、剪力、耐震軸力或耐震細節模組；雙軸混凝土壓力塊改用 320 條數值積分，另行重算第 6.4、9.3 節軸力算術，剪力分配所需 `Mprc` 改以連續中性軸獨立求解，強柱弱梁與圍束另行重算，共進行 117 項精確算術比對、14 項容許差比對及五組漂移哨兵。

此核心固定回報 `research-core-not-public` 與 `REVIEW`，不登錄首頁、不計入正式工具數，也不得輸出正式附件。第八版僅限完全包覆矩形 SRC 柱、置中雙對稱 H 型鋼骨與關於兩軸對稱的主筋配置，可接受軸壓加單向或雙向彎矩，並要求專案分析已納入第 7.4 節 P-Δ 效應。四項耐震子檢核中，剪力、強柱弱梁與圍束僅限強軸；剪力另限常重混凝土、整體澆置、垂直閉合箍筋及剪力釘貢獻明確為零。第 9.3 節的專案拉力強度、相接構材／接頭區傳力容量與免檢所需相關規定確認均由專案提供，工具不冒充容量來源或構架認定。例題 14 的十字型鋼骨只用於公式算術回歸，不冒充本核心可計斷面。catalog 以外型鋼性質來源、現況供貨與材證、弱軸耐震路徑、第 8.4.2 節接頭傳力比例、全構架所有接頭、柱腳／接頭、施工階段與其餘耐震細節仍維持失敗封閉或人工複核邊界。完整範圍與公式追溯見 `src-column-traceability.catalog.json`。
