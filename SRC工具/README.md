# SRC 構材工具

本目錄提供包覆型 SRC 梁正式工具：純函式核心、規範追溯、案件 JSON、精簡計算書、內部審閱／正式附件核可，以及真實瀏覽器列印驗證。公開入口為 `/src-beam`，首頁材料系統可直接切換至 SRC。

## 正式規範基準

- 內政部《鋼骨鋼筋混凝土構造設計規範與解說》100 年修正版，100 年 7 月 1 日施行。
- 法規入口：<https://www.nlma.gov.tw/ch/legislation/regsearch/977>
- 第 3 章：鋼骨寬厚比與一般要求。
- 第 5 章：包覆型 SRC 梁強度疊加、鋼骨／RC 剪力分擔、一般剪力與剪力摩擦控制。

2024 年內政部建築研究所已完成 SRC 設計與施工規範修正草案，但研究報告明列尚待後續規範審查。本核心不將草案當作現行法規。

## v0.1 適用範圍

- 完全包覆型矩形 SRC 梁，鋼骨為置中雙對稱 H 型斷面。
- 無軸力之撓曲與剪力檢核，非耐震設計。
- RC 撓曲部分支援單筋或雙筋矩形斷面，以平面應變與矩形壓力塊求中性軸，允許壓力筋未降伏。
- 鋼骨彎矩依 `Mns = ZFys`，整體設計彎矩依式 (5.4-1)。
- 剪力依式 (5.5-1) 與 (5.5-2) 分別檢核鋼骨及 RC 部分，不以單一相加容量掩蓋任一部分不符。
- RC 剪力同時計算一般剪力與剪力摩擦，取較小者。

## 失敗封閉邊界

下列條件不得用 v0.1 計算結果作通過判定：未知輸入 schema、耐震設計、軸力、非完全包覆、梁端主筋不連續或未錨定、主筋與鋼板淨距小於 25 mm、未明確確認常重混凝土與整體澆置剪力摩擦面、剪力釘貢獻、未納入的梁柱接頭與施工階段強度。

若未提供臨時支撐，混凝土凝固前的鋼梁靜載重強度與穩定必須另案複核；本項屬正式狀態的人工複核條件，不能因構材強度數值通過而消失。

## 獨立工程基準

`結構工具箱/tools/independent-engineering-benchmarks.catalog.json` 已將 `/src-beam` 納入正式入口獨立基準，包含 4 組案例與 41 項斷言。production 核心以應變相容與二分法求中性軸；獨立 oracle 在張力筋降伏、壓力筋彈性的明確適用域內改用二次方程封閉解，並獨立重算撓曲、400／490 MPa 寬厚比、鋼骨／RC 剪力分擔、一般剪力、剪力摩擦及需求比。

此基準失敗會阻擋平台的獨立工程基準 gate；SRC 梁現已計入 32 / 32 個正式工具入口。

## 正式操作頁與附件邊界

- `src-beam.html` 提供完整輸入、結果總覽與規範適用條件；工程名稱、編號及設計者均可留空，由主文承接，不影響附件核可。
- HTML 與計算書共用同一張「SRC 梁計算斷面圖」：混凝土及置中 H 型鋼依 `b、h、D、bf、tw、tf` 採用尺寸同比例繪製，並標示 `d、d′、dv、As、As′、Av/s`。現階段鋼筋只有計算面積與有效深度，圖面明確界定為計算斷面而非施工配筋詳圖；不臆造鋼筋根數、號數或層位。
- 案件 JSON 使用 `src-beam.case.v1`，匯入時檢查 schema、工具、版本與重算指紋；不一致時保留原輸入並失敗封閉。
- 計算書只列採用規範、構材條件、需求、斷面、材料、公式、代入值、檢核結果及結論。操作提醒、適用邊界卡與待複核閱讀狀態只留在 HTML 工作頁。
- 計算書預設為可列印的內部審閱；明確勾選核可後才成為正式附件。核可人與核可依據為選填，但核可後若變更，會自動撤銷並要求重新核可。
- 直接列印操作頁只顯示一頁封鎖通知；必須由「產生計算書」開啟附件輸出。
- `src-beam.contract.test.js` 固化報告純度、計算斷面、空白案件欄位、案件重播與指紋契約；`src-beam-browser-smoke.test.js` 以真實 Chromium 驗證圖面同步、無效幾何清除舊圖、JSON 往返、核可撤銷、列印媒體與正式 PDF。

正式 release 會把 SRC 梁 PDF、來源案件 JSON、計算指紋與雜湊證據寫入當輪私有證據目錄；公開頁只呈現完成數，不公開案件內容或雜湊。

## SRC 柱研究核心（尚未公開）

`core/src-column-core.js`、`src-column-core.test.js` 與獨立的 `core/src-column-oracle.js`／`src-column-oracle.test.js` 已建立 SRC 柱第二階段可審查核心，並以內政部建築研究所《鋼骨鋼筋混凝土(SRC)構造設計教材》例題 8 回歸。目前實作包含：

- 第 3.4 節表 3.4-2 翼板 `b/tf` 與腹板 `hc/tw` 自動重算；一般模式以 `λp` 判定，並保留教材例題採用的 `λpd` 參考值。
- 式 (7.3-3)~(7.3-6) 鋼骨與 RC 部分軸力／彎矩剛度分配。
- 式 (6.4-2)~(6.4-5) 包覆型 H 鋼骨有效迴轉半徑、細長比參數與軸壓強度。
- 式 (7.3-7)~(7.3-8) 鋼骨壓彎互制。
- 式 (7.3-9)~(7.3-10) 規範容許的鋼骨／RC 軸力與彎矩重新分配。
- RC 部分使用現行共用應變相容 P-M 核心，不以舊版查圖值取代斷面重算。
- 獨立 oracle 不引用正式核心或共用 P-M 模組，對寬厚比、剛度分配、鋼骨軸壓／互制與重新分配進行 30 項算術交叉比對；RC 應變相容 P-M 尚未納入獨立覆蓋。

此核心固定回報 `research-core-not-public` 與 `REVIEW`，不登錄首頁、不計入正式工具數，也不得輸出正式附件。第二版僅限完全包覆矩形 SRC 柱、置中雙對稱 H 型鋼骨、軸壓加 x 向單向彎矩，並要求專案分析已納入第 7.4 節 P-Δ 效應。型鋼 A、Ix、Iy、Zx 的資料庫來源與幾何反算核對、獨立 RC P-M oracle、雙向彎矩、柱剪力、柱腳／梁柱接頭、施工階段與第 9 章耐震設計尚未完成，都維持失敗封閉或人工複核邊界。完整範圍與公式追溯見 `src-column-traceability.catalog.json`。
