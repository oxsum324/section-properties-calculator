# 接收端補充證據範本

接收端回簽助手可把 RVR v5 五類補充查核中經常重複的文字與文件定位資料保存為本機範本。範本的用途是減少重複輸入，不是保存或替代正式證據。

## 範本保存內容

- 補充查核類別
- 查核依據
- 文件編號
- 文件版次
- 文件日期
- 頁碼或章節

範本明確不保存證據檔名及 SHA-256。套用範本後，該列會維持證據未完成狀態，使用者必須重新選取本案實際文件，由瀏覽器重新計算檔名與 SHA-256，才能建立 RVR。

## 操作方式

1. 在某一交接列將補充查核設為「通過」，填妥查核依據及文件受控欄位。
2. 按「儲存為範本」。同一查核類別、文件編號、版次、日期與頁碼再次儲存時會更新原範本。
3. 在個別查核的「套用本機範本」選單套用，或在範本庫按「套用至全部同類列」。
4. 對每一列重新選取實際證據檔；範本不會帶入舊檔名或舊雜湊。
5. 如需移轉至其他電腦，匯出 `receiver-supplemental-evidence-template-library` JSON，再於另一個瀏覽器匯入。

## 安全與責任邊界

- 範本庫 schema v1 最多保存 100 筆，匯入檔上限 1 MB。
- 匯入時會驗證種類、版本、時間、日期、五類查核識別及「不含檔名／雜湊」邊界；含有 `fileName` 或 `fileSha256` 的範本會被拒絕。
- 範本只保存在瀏覽器 `localStorage`，不會寫入來源專案、PDF、DOCX、ERH、RVR、SEV 或 SCV。
- 套用範本不是工程核可，也不證明文件仍為最新版或適用於目前案件。接收端仍須逐案核對模型、構造、版次、日期、頁碼及工程內容。
- RVR v5 仍要求每個標示通過的補充查核具有完整實際證據；SEV v2 仍由來源端逐檔重算 SHA-256。
